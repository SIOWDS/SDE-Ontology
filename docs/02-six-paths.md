# 六路径发生学

S、D、E 的六种有序排列构成六条基本分析路径：

| 路径 | 起点 | 中介 | 显著问题 |
|---|---|---|---|
| S→D→E | 已显露结构 | 差异运行 | 结构如何通过行动重写环境 |
| S→E→D | 已显露结构 | 环境组织 | 结构如何借环境选择路径 |
| D→S→E | 差异序列 | 结构形成 | 运行如何凝结并扩散影响 |
| D→E→S | 差异序列 | 环境重组 | 路径如何改造条件后形成新结构 |
| E→S→D | 特征纠缠 | 结构约束 | 环境如何先塑形再导向行动 |
| E→D→S | 特征纠缠 | 差异生成 | 条件如何经路径形成结构 |

六路径不是六个彼此排斥的世界模型，而是同一发生系统的六种进入方式。在复杂案例中，多条路径可以并行、竞争、嵌套或发生相变。
