# SDE 与 SIO

## 定位

SDE 是发生本体论框架。SIO 是 S 维度中成熟、稳定显露的一种三视角结构：

- O：Objective Body，客体
- I：Interactive Body，互动体
- S：Subjective Body，主体

## 关键区分

主体、互动体和客体不应被理解为三个先在实体。它们是一个发生复合体稳定显露之后，从不同号位获得的结构性辨认。

因此：

1. SIO 是 SDE 的稳定显露，不是与 SDE 并列的第二套本体论；
2. SIO 适合描述已经形成一定边界和角色结构的复合体；
3. SDE 进一步解释该结构如何发生、如何变化以及如何解体或再生。

## 知识论含义

认识的对象不是孤立主体或孤立客体，而是主体—互动体—客体共同形成的复合存在。知识因互动而诞生、传播、改变，也可能因互动条件消失而死亡。
