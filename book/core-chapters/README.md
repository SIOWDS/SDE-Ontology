## 核心关系

> 在 E 中，经 D，成 S。

\[
S=F(D,E),\qquad D=G(S,E),\qquad E=H(S,D)
\]

F、G、H 是三种生成关系的占位符；理论重点在于 S、D、E 的非线性互生，而不在占位字母本身。
